# 🤖 AI Hand Gesture Recognition System

A real-time AI-powered hand gesture recognition system built using Python, OpenCV, and MediaPipe.

## 🚀 Features

* Real-time hand tracking
* Multiple gesture recognition
* AI-style futuristic UI
* Voice feedback system
* FPS counter
* Confidence score display
* Finger counting
* Smooth webcam interaction

## 🛠 Technologies Used

* Python
* OpenCV
* MediaPipe
* Pyttsx3
* NumPy

## 🎯 Recognized Gestures

| Gesture   | Meaning          |
| --------- | ---------------- |
| FIST      | Closed Hand      |
| ONE       | One Finger       |
| PEACE     | Victory Sign     |
| PALM      | Stop Gesture     |
| OPEN HAND | All Fingers Open |
| ROCK      | Rock Sign        |
| THUMBS UP | Approval         |

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/niha-rika-ai/AI-Hand-Gesture-Recognition.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python gesture_ai.py
```

## 🎮 Controls

* Press `Q` to exit the application.
